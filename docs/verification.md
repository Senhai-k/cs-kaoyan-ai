## 3. 数据质量

### 原则

- 关键招生数据必须关联官方来源。
- 官网入口、精确公告和原文片段不可混为同一证据层级。
- 数字必须区分学校、学院、专业、年份和统计口径。
- 首页和详情只使用已发布数据；AI 未命中证据时不生成确定性数字。
- 来源失效、正文变化和数据过期进入运营任务，不静默覆盖。

## 5. 已知限制

- `catalog-408-2026.json` 是 2026 研招网当前目录中项目定义的计算机核心专业完整分页批次，不代表所有历史年份或所有学科范围。
- 当前开发机未安装 Tesseract 与 `chi_sim`，真实中文扫描件 OCR 未验收。
- 当前模型供应商不公开输入/输出单价，规划实验使用 `UNMETERED`，可审计 Token 用量但不提供单次美元成本。
- 当前机器访问 Docker Hub 不稳定，完整演练使用 `docker.m.daocloud.io`；目标环境应选择可信且可达的镜像源。
- webhook 本机投递闭环已验证，组织实际通知系统仍需由部署方提供 `ALERT_WEBHOOK_URL` 后复验。
- H2 适合开发与演示，正式运行应使用 MySQL、备份和恢复流程。
