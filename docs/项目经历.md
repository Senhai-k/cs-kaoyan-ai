# 项目经历

## 计算机考研择校与知识库智能体系统

**项目角色：** 后端 / AI 应用开发  
**技术栈：** Spring Boot 3、Java 17、MySQL、Flyway、React、TypeScript、LangGraph、LangChain、Qdrant、BGE、BM25、Docker Compose、Prometheus

### 项目描述

针对考研院校数据分散、来源难核验和择校依赖人工判断的问题，开发集院校筛选、智能推荐、数据对比、私域知识库问答和资料运营于一体的全栈系统。

### 主要工作

- 使用 LangGraph 构建可规划、可调用工具、可并行执行和可中断恢复的智能体工作流，引入状态持久化、人工审核和证据发布机制。
- 完成文档解析、切片、BGE 向量化、Qdrant 与 BM25 混合检索、结果融合、二次排序和有依据生成的完整 RAG 链路。
- 建立 RAG、规划器和证据策略评估体系；30 条困难案例中 Recall@5 达到 100%、目标 Recall@1 达到 93.33%、MRR@5 达到 98.08%，真实 LLM 规划 A/B 达到 10/10 Exact Match。
- 设计资料导入、质量检查、人工审核、原子发布、版本回滚和官网变化监测流程，管理 56 所院校、142 条来源和 133 份知识资料。
- 使用 MySQL、Flyway、RBAC、异步任务、操作日志和异常处理完善后端工程能力，并通过 Docker Compose、Prometheus 和链路追踪实现部署与监控。
- 建立自动化质量门禁，完成 Spring 65 项、Agent 65 项、前端 70 项和 Playwright 33 项测试。
